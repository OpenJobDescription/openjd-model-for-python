# Quality Evaluation Reports

This directory holds quality evaluation reports for the Rust→Python bindings
in `rust-bindings/`. Reports are generated by the `eval-bindings` skill (see
`skills/eval-bindings/SKILL.md`).

Reports follow the naming convention:

- `expr-bindings-quality-evaluation-report.md`
- `model-bindings-quality-evaluation-report.md`
- `sessions-bindings-quality-evaluation-report.md`

Each report has a numbered Recommendations section. When you implement a
recommendation, mark the item resolved in the same commit by striking it
through with `~~` and appending `**Resolved.**` or `**Resolved** — <note>.`,
mirroring the workflow in `~/openjd-rs/reports/`.
